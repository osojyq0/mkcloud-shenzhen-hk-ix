## 深港 IX 是一条什么线路

先说 IX。IX（互联网交换中心）是多个网络在同一个物理位置交换流量的设施。Mkcloud 的深港 IX，官方名称是“深港上云互联优化专线”，它不是普通公网 VPS：入口 IP 只在交换中心内网宣告，只有加入了 IX 的大厂云网络（阿里云、腾讯云这类）能连进来，公网路由根本到不了入口。你需要用一台符合条件的云服务器做“前置机”连入，业务流量再从香港 BGP 出口发出去。

每台 VPS 分配 1 个独立入口 IP 加 1 个独立出口 IP，官方叫“单端双独立 IP”。这个设计直接决定了它的用法：入口只用来连，出口只用来出。跨境电商后台操作、API 调用、文件上传这类“从 VPS 向外访问”的场景是正路；想拿它对外建站、收支付回调、跑游戏服务端，行不通——出口不接收外部连入。

延迟方面，官方给的端内参考是 1~2ms。注意“端内”两个字：指的是从云厂网络进入专线后到香港出口那一段，不等于你本地电脑到目标网站的完整耗时。真实体验等于四段叠加：本地到前置机、前置机进 IX、端内传输、香港到目标。第三方博主 catcat.blog 在 2026 年初的实测里用火山引擎 ECS 做前置，入口延迟在个位数毫秒量级，和这个参考值对得上。

## 接入条件：前置机是绕不开的一步

深港 IX 不限连入省份，这是它和广港、沪港 IPLC 直连产品最大的区别——直连产品绑定一个省份，只有该省份的 IP 能连入口。但“不限省份”不等于“任意网络直连”，入口只接受特定云厂 BGP 网络：腾讯云国内全网、百度云国内全网、火山云华南、华为云华南。阿里云目前提示“暂时不通”，而且这条线路的状态今年以来反复变过，Telegram 通知群里能看到阿里云线路中断又恢复的记录。下单前自己看一眼购物车当前提示，比信任何文章都靠谱。

前置机本身有成本，别漏算。catcat.blog 的测评提到，性价比高的前置方案集中在阿里云、腾讯云轻量实例（标称 200M 带宽），但已有实例被限速到 20M 甚至 1M 的案例；火山引擎没有轻量形态，按量流量约 0.8 元/GB，长期跑量不算便宜。该博主自己的测试环境是火山 ECS 加流量包，一年下来前置开销并不小。选前置时带宽稳定性和流量单价，比机器月租更值得看。

## 怎么选：哪一档适合你

判断顺序建议是：先确认你能不能接入（有没有支持范围内的前置），再看流量档，最后才是配置。

- **2 核 4G/1G 峰值/2TB（¥158/月）**：入门档。一个人跑几个店铺后台、日常 API 调用和文件传输，够用。第三方汇总把深港 IX 称为 Mkcloud 性价比最高的线路，指的主要就是这一档。
- **4TB（¥258）和 6TB（¥378）**：前者加流量，后者把带宽提到 2G 峰值。有多台前置机、上传素材频繁，从这两档里挑。
- **10TB 到 50TB**：多人小团队或直播推流类用途。记住流量双向合计，20TB 档按“单向下载”估算要除以二。
- **100TB 及以上（¥7168 起）**：给企业级批量任务准备的，个人业务基本碰不到这个量级，看看就好。
- **独享档（¥1600/月起）**：适合对持续速率有硬要求的场景，价位和共享档完全不在一个维度，别拿它俩比性价比。

还有一个容易被忽略的对比：广港直连（IEPL）和深港 IX 同配置价格接近，但广港入口走腾讯广州八线 BGP、要绑定连入省份，不需要前置机；深港 IX 不限省份、必须云厂前置。官方知识库自己都说“广州就选广港、深圳就选 IX”过于简单——已经有云厂机器的，IX 更顺；没有且不想买前置的，直连反而省事。

## 常见问题

**需要自己的 ASN 或 IXP 端口吗？** 不需要。零售用户只需要一台支持范围内的云厂机器做前置，交换中心成员接入是另一类企业服务，和个人购买无关。

**阿里云轻量能当前置吗？** 目前深港 IX 购物车提示阿里云国内全网“暂时不通”。这个状态今年反复变化过，下单前以页面当前提示为准，也可以先问客服确认。

**流量怎么算？** 上行加下行双向合计。2TB 档大约相当于单向 1TB 的下载量。超量后停机，可购流量重置或补差价升级。

**能建站吗？** 不能。出口不接收外部连入，公开网站、支付回调、邮件接收、游戏服务端都不行。这是产品形态决定的，不是配置能绕开的。

**1G 峰值等于每秒 1GB 吗？** 不是。1Gbps 理论约 125MB/s，实际受协议开销、磁盘性能和目标服务限速影响还会更低。

**和沪港 IX 怎么选？** 两者出口都是香港 BGP，差别在入口位置和端内延迟：深港 IX 约 1~2ms、沪港 IX 约 21ms。业务或云资源在上海周边，沪港 IX 更顺；华南云资源则选深港 IX。

最后收一下。深港 IX 解决的是一个很具体的问题：把跑在云上的业务，用一条低延迟、固定双 IP 的路径接到香港出口。它的边界也同样具体——需要前置机、不能对外服务、必须实名、无 SLA。这些条件和价格一样摆在明面上，能接受就值得下单，接受不了，广港直连或普通海外 VPS 可能反而是更合适的选择。
